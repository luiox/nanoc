# NanoC 字节码格式规范 v2.0 (NCI)

## 1. 概述

NCI（NanoC Intermediate）是 NanoC 虚拟机的二进制字节码格式。它是一种紧凑的、可直接执行的二进制格式，支持外部符号引用，便于与 C 语言进行互操作。

### 1.1 设计目标

1. **紧凑性**：相比文本格式（.nas），文件大小压缩 10 倍以上
2. **快速加载**：无需解析文本，直接加载到内存执行
3. **符号支持**：支持导入/导出符号表，支持与 C 函数互操作
4. **静态链接**：汇编时可解析符号地址，生成独立可执行文件
5. **可扩展性**：保留足够的扩展空间用于未来特性

## 2. 文件格式

### 2.1 整体布局

```
+------------------+
| 文件头 (32 字节)  |
+------------------+
| 导入表 (可变)    |
+------------------+
| 导出表 (可变)    |
+------------------+
| 代码段 (可变)    |
+------------------+
| 数据段 (可变)    |
+------------------+
| 调试信息 (可选)  |
+------------------+
```

### 2.2 文件头（32 字节）

所有多字节值使用**小端序**（little-endian）。

```
偏移  大小  字段名        描述
0     6     magic         魔数 "NanoC\0" (0x4E, 0x61, 0x6E, 0x6F, 0x43, 0x00)
6     2     reserved      保留（必须为 0）
8     4     headerSize    文件头总大小（包括所有表头，固定为 32）
12    4     codeSize      代码段大小（字节）
16    4     dataSize      数据段大小（字节）
20    4     importCount   导入符号数量
24    4     exportCount   导出符号数量
28    4     entryPoint    入口点偏移（相对于代码段起始）
```

#### 2.2.1 魔数

魔数为 "NanoC\0" 6 个 ASCII 字符 + 2 字节保留，共 8 字节对齐：
- 'N' (0x4E)
- 'a' (0x61)
- 'n' (0x6E)
- 'o' (0x6F)
- 'C' (0x43)
- '\0' (0x00)
- 保留 (0x00, 0x00)

#### 2.2.2 标志位（flags）

当前版本不使用标志位，reserved 字段必须为 0。未来可扩展：
```
位 0: 0=32 位模式，1=64 位模式（保留）
位 1: 0=小端序，1=大端序（当前仅支持小端序）
位 2: 0=无调试信息，1=有调试信息
位 3-15: 保留（必须为 0）
```

### 2.3 导入表（Import Table）

导入表位于文件头之后，包含所有需要从外部导入的符号（如 C 函数）。

#### 2.3.1 导入表头（8 字节）

```
偏移  大小  描述
0     4     导入表总大小（包括表头）
4     4     导入符号数量（与文件头中的 importCount 一致）
```

#### 2.3.2 导入符号条目（每个 8 字节 + 名称长度）

```
偏移  大小  描述
0     4     符号名称长度（不含结尾的\0）
4     4     符号地址（汇编时静态链接填实际地址，动态链接为 0）
8     N     符号名称（ASCII，不含\0）
8+N   1     填充字节（0x00，使总长度为 8 的倍数）
```

**示例**：导入 `printf` 函数（静态链接，地址 0x08049000）

```
06 00 00 00  00 90 04 08  70 72 69 6E 74 66 00 00
↑              ↑              ↑
符号名长度=6   地址=0x08049000  符号名"printf" + \0 + 填充
```

**示例**：导入 `printf` 函数（动态链接，地址待填充）

```
06 00 00 00  00 00 00 00  70 72 69 6E 74 66 00 00
↑              ↑              ↑
符号名长度=6   地址=0 (待链接)  符号名"printf" + \0 + 填充
```

#### 2.3.3 静态链接 vs 动态链接

**静态链接**：
- 汇编时通过 `-l` 参数指定库文件
- 汇编器解析符号地址并填入导入表
- 生成的 NCI 文件可直接执行

**动态链接**：
- 导入表地址字段为 0
- 虚拟机加载时解析符号地址
- 支持运行时库加载

### 2.4 导出表（Export Table）

导出表位于导入表之后，包含所有对外可见的符号（如可供 C 调用的函数）。

#### 2.4.1 导出表头（8 字节）

```
偏移  大小  描述
0     4     导出表总大小（包括表头）
4     4     导出符号数量（与文件头中的 exportCount 一致）
```

#### 2.4.2 导出符号条目（每个 8 字节 + 名称长度）

```
偏移  大小  描述
0     4     符号名称长度（不含结尾的\0）
4     4     符号地址偏移（相对于代码段起始）
8     N     符号名称（ASCII，不含\0）
8+N   1     填充字节（0x00，使总长度为 8 的倍数）
```

**示例**：导出 `main` 函数（假设地址为 0x00000020）

```
04 00 00 00  20 00 00 00  6D 61 69 6E 00 00 00 00
↑              ↑              ↑
符号名长度=4   地址=32         符号名"main" + \0 + 填充
```

### 2.5 代码段（Code Section）

代码段包含所有指令的二进制编码。指令是变长的。

#### 2.5.1 指令编码

| 类别 | 格式 | 长度 | 示例 |
|------|------|------|------|
| 无操作数 | `OP` | 1 字节 | RET |
| 单寄存器 | `OP R` | 2 字节 | PUSH R0 |
| 寄存器 + 立即数 | `OP R IMM32` | 6 字节 | LMM R0, 100 |
| 寄存器 + 寄存器 | `OP R1 R2` | 3 字节 | ADD R0, R1 |
| 跳转 (绝对) | `OP ADDR32` | 5 字节 | JMP 0x1000 |
| 外部调用 | `OP IMM32` | 5 字节 | CALLX 0x08049000 |

## 3. 指令集

### 3.1 操作码表

#### 3.1.1 内存访问指令（0x00-0x0F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| LMM | 0x00 | R, IMM32 | 6 字节 | 加载立即数到寄存器 |
| ST | 0x01 | R, ADDR32 | 6 字节 | 存储寄存器到内存 |
| LEA | 0x02 | R, ADDR32 | 6 字节 | 加载有效地址 |
| LOAD | 0x03 | R1, R2 | 3 字节 | 从内存加载到寄存器（间接寻址） |
| STORE | 0x04 | R1, R2 | 3 字节 | 从寄存器存储到内存（间接寻址） |

#### 3.1.2 算术运算指令（0x10-0x1F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| ADD | 0x10 | R, IMM32/R | 3/6 字节 | 加法 |
| SUB | 0x11 | R, IMM32/R | 3/6 字节 | 减法 |
| MUL | 0x12 | R, IMM32/R | 3/6 字节 | 乘法 |
| DIV | 0x13 | R, IMM32/R | 3/6 字节 | 除法 |
| MOD | 0x14 | R, IMM32/R | 3/6 字节 | 取模 |
| NOT | 0x15 | R | 2 字节 | 按位取反 |

#### 3.1.3 逻辑运算指令（0x20-0x2F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| AND | 0x20 | R, IMM32/R | 3/6 字节 | 按位与 |
| OR | 0x21 | R, IMM32/R | 3/6 字节 | 按位或 |
| XOR | 0x22 | R, IMM32/R | 3/6 字节 | 按位异或 |
| SHL | 0x23 | R, IMM32/R | 3/6 字节 | 逻辑左移 |
| SHR | 0x24 | R, IMM32/R | 3/6 字节 | 逻辑右移 |

#### 3.1.4 比较指令（0x30-0x3F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| EQ | 0x30 | R, IMM32/R | 3/6 字节 | 等于比较 |
| NE | 0x31 | R, IMM32/R | 3/6 字节 | 不等于比较 |
| LT | 0x32 | R, IMM32/R | 3/6 字节 | 小于比较 |
| LE | 0x33 | R, IMM32/R | 3/6 字节 | 小于等于比较 |
| GT | 0x34 | R, IMM32/R | 3/6 字节 | 大于比较 |
| GE | 0x35 | R, IMM32/R | 3/6 字节 | 大于等于比较 |

#### 3.1.5 栈操作指令（0x40-0x4F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| PUSH | 0x40 | R | 2 字节 | 压栈 |
| POP | 0x41 | R | 2 字节 | 出栈 |
| ENTER | 0x42 | SIZE16 | 3 字节 | 建立栈帧（分配局部变量空间） |
| LEAVE | 0x43 | - | 1 字节 | 清理栈帧 |

#### 3.1.6 控制流指令（0x50-0x5F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| JMP | 0x50 | ADDR32 | 5 字节 | 无条件跳转 |
| JIC | 0x51 | ADDR32 | 5 字节 | 条件跳转（根据 flags 寄存器） |

#### 3.1.7 函数调用指令（0x60-0x6F）

| 操作码 | 值 | 指令 | 格式 | 长度 | 描述 |
|--------|-----|------|------|------|------|
| CALL | 0x60 | ADDR32 | 5 字节 | 内部函数调用（代码段内偏移） |
| CALLX | 0x61 | IMM32 | 5 字节 | 外部函数调用（绝对地址） |
| RET | 0x62 | - | 1 字节 | 函数返回 |

#### 3.1.8 系统调用（通过外部函数实现）

**注意**：v2.0 移除了 TRAP 指令，系统调用通过外部函数实现：

| 功能 | C 函数签名 | 说明 |
|------|-----------|------|
| GETCH | `int getch(void)` | 读取一个字符 |
| OUTCH | `void outch(char c)` | 输出一个字符 |
| HALT | `void halt(void)` | 停止程序执行 |
| PRINTF | `int printf(const char* fmt, ...)` | 格式化输出 |
| MALLOC | `void* malloc(size_t size)` | 动态内存分配 |
| FREE | `void free(void* ptr)` | 释放内存 |

### 3.2 寄存器编码

| 寄存器 | 编码值 |
|--------|--------|
| R0 (AX) | 0x00 |
| R1 | 0x01 |
| R2 | 0x02 |
| R3 | 0x03 |
| R4 | 0x04 |
| R5 | 0x05 |
| R6 | 0x06 |
| R7 | 0x07 |

**说明**：
- R0 也称为 AX，用于函数返回值
- R4-R7 为被调用者保护寄存器
- R0-R3 为调用者保护寄存器

### 3.3 条件码（用于 JIC 指令）

条件跳转基于 `flags` 寄存器的状态：

| 条件 | 标志位 | 描述 |
|------|--------|------|
| Z (Zero) | bit 0 | 上一次比较结果为零 |
| N (Negative) | bit 1 | 结果为负数 |
| P (Positive) | bit 2 | 结果为正数 |
| O (Overflow) | bit 3 | 溢出 |

## 4. 新增指令详细说明

### 4.1 LOAD 指令（间接寻址）

**功能**：从寄存器指向的内存地址加载数据到另一个寄存器

**格式**：`load Rdest, [Rsrc]`

**编码**：
```
0x03 | Rdest | Rsrc
```

**示例**：`load R1, [R0]`
```
03 01 00
```

**执行**：`Rdest = mem[Rsrc]`

### 4.2 STORE 指令（间接寻址）

**功能**：将寄存器值存储到寄存器指向的内存地址

**格式**：`store [Rdest], Rsrc`

**编码**：
```
0x04 | Rdest | Rsrc
```

**示例**：`store [R0], R1`
```
04 00 01
```

**执行**：`mem[Rdest] = Rsrc`

### 4.3 ENTER 指令（栈帧建立）

**功能**：为函数调用建立栈帧，分配局部变量空间

**格式**：`enter size`（size 为 16 位无符号整数，表示字节数）

**编码**：
```
0x42 | size_low | size_high
```

**示例**：`enter 32`（分配 32 字节局部变量空间）
```
42 20 00
```

**执行**：
```
push BP           ; 保存旧的基址指针
BP = SP           ; 设置新的基址指针
SP = SP - size    ; 分配局部变量空间
```

### 4.4 LEAVE 指令（栈帧清理）

**功能**：清理函数栈帧，恢复调用者栈帧

**格式**：`leave`

**编码**：
```
0x43
```

**执行**：
```
SP = BP           ; 恢复栈指针
pop BP            ; 恢复基址指针
```

### 4.5 CALL 指令（内部函数调用）

**功能**：调用代码段内的函数

**格式**：`call addr`（addr 为代码段内偏移）

**编码**：
```
0x60 | addr_low | addr_mid1 | addr_mid2 | addr_high
```

**示例**：`call 0x00000020`
```
60 20 00 00 00
```

**执行**：
```
push PC+5         ; 保存返回地址
PC = addr
```

### 4.6 CALLX 指令（外部函数调用）

**功能**：调用外部函数（绝对地址）

**格式**：`callx addr`（addr 为外部函数绝对地址）

**编码**：
```
0x61 | addr_low | addr_mid1 | addr_mid2 | addr_high
```

**示例**：`callx 0x08049000`（调用地址为 0x08049000 的外部函数）
```
61 00 90 04 08
```

**执行**：
```
push PC+5         ; 保存返回地址
PC = addr
```

**C 调用约定**：
- 参数：通过栈传递（调用者压栈，从右到左）
- 返回值：通过 AX 寄存器（R0）返回
- 栈清理：调用者负责清理参数（cdecl）

### 4.7 RET 指令（函数返回）

**功能**：从函数返回到调用者

**格式**：`ret`

**编码**：
```
0x62
```

**执行**：
```
pop PC            ; 恢复返回地址
```

## 5. 示例

### 5.1 简单程序

源代码：
```c
int main() {
    int a = 10;
    int b = 20;
    return a + b;
}
```

字节码（十六进制）：
```
# 文件头（32 字节）
4E 61 6E 6F 43 00 00 00     # magic = "NanoC\0" + reserved
20 00 00 00                 # headerSize = 32
0E 00 00 00                 # codeSize = 14
00 00 00 00                 # dataSize = 0
00 00 00 00                 # importCount = 0
00 00 00 00                 # exportCount = 0
00 00 00 00                 # entryPoint = 0

# 导入表（空）
# 导出表（空）

# 代码段
00 00 0A 00 00 00           # LMM R0, 10
00 00 14 00 00 00           # LMM R1, 20
10 00 01                    # ADD R0, R1 (寄存器模式：R0 += R1)
40 00                       # PUSH R0
41 00                       # POP R0
62                          # RET
```

### 5.2 调用外部 C 函数（静态链接）

汇编源代码（.nas）：
```asm
; 声明外部函数（静态链接）
extern printf 0x08049000

main:
    lmm R0, 42              ; 参数：42
    push R0                 ; 压栈参数
    callx 0x08049000        ; 调用 printf（静态链接地址）
    add R0, 4               ; 清理栈（1 个参数 * 4 字节）
    lmm R0, 0               ; 返回值 0
    ret
```

字节码结构：
```
# 文件头
magic = "NanoC\0"
importCount = 1
exportCount = 1
entryPoint = 0

# 导入表（printf，地址 0x08049000）
06 00 00 00  00 90 04 08  70 72 69 6E 74 66 00 00

# 导出表（main，地址 0x00000020）
04 00 00 00  20 00 00 00  6D 61 69 6E 00 00 00 00

# 代码段
... printf 调用代码 ...
```

### 5.3 调用外部 C 函数（动态链接）

汇编源代码（.nas）：
```asm
; 声明外部函数（动态链接，地址由 VM 解析）
extern printf

main:
    lmm R0, 42
    push R0
    callx 0                 ; 调用导入表第 1 个函数（索引 0）
    add R0, 4
    lmm R0, 0
    ret
```

虚拟机加载时：
1. 读取导入表，找到 `printf` 符号
2. 通过 `dlsym`/`GetProcAddress` 解析 `printf` 地址
3. 填入 CALLX 指令的地址字段

### 5.4 函数调用与栈帧

```c
int add(int a, int b) {
    int c = a + b;
    return c;
}

int main() {
    return add(10, 20);
}
```

汇编代码：
```asm
add:
    enter 4                 ; 分配 4 字节局部变量（c）
    ; 参数：[BP+8]=a, [BP+12]=b
    lmm R0, 8
    lea R0, [BP+R0]         ; R0 = &a
    load R0, [R0]           ; R0 = a
    
    lmm R1, 12
    lea R1, [BP+R1]         ; R1 = &b
    load R1, [R1]           ; R1 = b
    
    add R0, R1              ; R0 = a + b
    
    st R0, 0                ; c = R0 (相对于 BP 的偏移 0)
    load R0, [BP]           ; 返回值 = c
    leave
    ret

main:
    lmm R0, 20
    push R0                 ; 参数 b
    lmm R0, 10
    push R0                 ; 参数 a
    call add
    add R0, 8               ; 清理栈（2 个参数 * 4 字节）
    ret
```

## 6. C 语言互操作

### 6.1 调用约定（cdecl）

NanoC 遵循 C 语言的 cdecl 调用约定：

1. **参数传递**：从右到左压栈
2. **返回值**：通过 AX 寄存器（或 R0）返回
3. **栈清理**：调用者负责清理参数
4. **寄存器保护**：
   - 被调用者保护：R4-R7（callee-saved）
   - 调用者保护：R0-R3（caller-saved）

### 6.2 数据类型映射

| NanoC 类型 | C 类型 | 大小 | 说明 |
|-----------|-------|------|------|
| int | int32_t | 4 字节 | 有符号整数 |
| char | int8_t | 1 字节 | 字符（提升为 int 传递） |
| void | void | 0 字节 | 无类型 |
| T* | T* | 4 字节 | 指针（32 位地址） |

### 6.3 外部函数声明

在 NanoC 代码中调用 C 函数，需要声明外部函数：

```c
// NanoC 代码
extern int printf(char* fmt, ...);
extern int scanf(char* fmt, ...);
extern void* malloc(int size);
extern void free(void* ptr);
extern int getch(void);
extern void outch(char c);
extern void halt(void);

int main() {
    printf("Hello, World!\n");
    outch('\n');
    halt();
    return 0;
}
```

编译时，这些函数会被记录到导入表中。链接时，链接器会解析这些符号的实际地址。

### 6.4 系统调用迁移

v2.0 移除了 TRAP 指令，系统调用改为外部函数：

**旧方式（TRAP）**：
```asm
trap 0x01    ; OUTCH
```

**新方式（外部函数）**：
```asm
; 声明外部函数
extern outch

; 调用
lmm R0, 'A'
push R0
callx outch
add R0, 4    ; 清理栈
```

**优势**：
1. 统一函数调用机制，减少特殊指令
2. 支持更灵活的参数传递（可变参数）
3. 便于与 C 标准库集成
4. 简化虚拟机实现（减少 TRAP 处理逻辑）

## 7. NAS 汇编器语法

### 7.1 外部符号声明

```asm
; 静态链接（指定地址）
extern printf 0x08049000
extern malloc 0x0804A000

; 动态链接（地址由 VM 解析）
extern printf
extern malloc
```

### 7.2 导出符号声明

```asm
; 导出 main 函数
export main

; 导出多个函数
export main, helper, util_function
```

### 7.3 调用外部函数

```asm
; 使用 CALLX 调用外部函数
callx printf
callx 0x08049000    ; 直接使用地址
```

### 7.4 完整示例

```asm
; hello.nas
extern printf
export main

main:
    ; printf("Hello, World!\n")
    lea R0, .msg
    push R0
    callx printf
    add R0, 4
    
    ; return 0
    lmm R0, 0
    ret

.msg:
    db "Hello, World!\n", 0
```

## 8. 实现注意事项

### 8.1 字节序

所有多字节值使用**小端序**（little-endian）：
- 32 位整数：低字节在前
- 16 位整数：低字节在前

### 8.2 对齐

- 文件头：自然对齐（32 字节）
- 导入/导出表条目：8 字节对齐（通过填充）
- 指令：无需特殊对齐

### 8.3 错误处理

加载 NCI 文件时应检查：
1. 魔数是否正确（"NanoC\0"）
2. 保留字段是否为 0
3. 文件大小是否与头信息一致
4. 导入符号是否都能解析（动态链接模式）

### 8.4 向后兼容

- 保留对旧版 NCO 格式的读取支持（魔数 "NCO\0"）
- 新版本文件应拒绝在旧版本 VM 上运行（通过 version 字段）
