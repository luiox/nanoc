# NanoC 字节码格式规范 (NCO)

## 1. 概述

NCO（NanoC Object）是NanoC虚拟机的二进制字节码格式。它是一种紧凑的、可直接执行的二进制格式。

## 2. 文件格式

### 2.1 文件头（16字节）

```
偏移  大小  描述
0     4     魔数 "NCO\0" (0x4E, 0x43, 0x4F, 0x00)
4     2     版本号 (当前: 0x0001)
6     2     标志位 (保留)
8     4     代码段大小 (字节)
12    4     入口点偏移 (相对于代码段起始)
```

## 3. 指令编码

### 3.1 指令格式分类

| 类别 | 格式 | 长度 | 示例 |
|------|------|------|------|
| 无操作数 | `OP` | 1字节 | RET, HALT |
| 单寄存器 | `OP R` | 2字节 | PUSH R0, POP R0 |
| 寄存器+立即数 | `OP R IMM32` | 6字节 | LMM R0, 100 |
| 双寄存器 | `OP R1 R2` | 3字节 | ADD R0, R1 |
| 跳转(绝对) | `OP ADDR32` | 5字节 | JMP 0x1000 |
| 跳转(相对) | `OP OFFSET32` | 5字节 | JMP +10 |
| 陷阱 | `OP TYPE` | 2字节 | TRAP HALT |

| 操作码 | 值 | 指令 | 格式 | 描述 |
|--------|-----|------|------|------|
| 0x00 | 0 | LMM | R, IMM32 | 加载立即数到寄存器 |
| 0x01 | 1 | ST | R, ADDR32 | 存储寄存器到内存 |
| 0x02 | 2 | LEA | R, ADDR32 | 加载有效地址 |
| 0x03 | 3 | ADD | R, IMM32/R | 加法 |
| 0x04 | 4 | SUB | R, IMM32/R | 减法 |
| 0x05 | 5 | MUL | R, IMM32/R | 乘法 |
| 0x06 | 6 | DIV | R, IMM32/R | 除法 |
| 0x07 | 7 | MOD | R, IMM32/R | 取模 |
| 0x08 | 8 | NOT | R | 按位取反 |
| 0x09 | 9 | AND | R, IMM32/R | 按位与 |
| 0x0A | 10 | OR | R, IMM32/R | 按位或 |

## 4. 示例

### 4.1 简单程序

源代码：
```c
int main() {
    int a = 10;
    int b = 20;
    return a + b;
}
```

字节码（十六进制）：
```
4E 43 4F 00 01 00 00 00 00 00 24 00 00 00 00 00  ; 文件头
00 00 0A 00 00 00                                ; LMM R0, 10
14 00                                            ; PUSH R0
00 00 14 00 00 00                                ; LMM R0, 20
14 00                                            ; PUSH R0
15 01                                            ; POP R1
15 00                                            ; POP R0
03 00 01 00 00 00                                ; ADD R0, R1
14 00                                            ; PUSH R0
15 00                                            ; POP R0
19                                               ; RET
```

## 5. 实现注意事项

1. **字节序**：所有多字节值使用小端序（little-endian）
2. **对齐**：指令不需要特殊对齐
3. **扩展性**：保留足够的操作码空间用于未来扩展
4. **调试信息**：可选的调试段可以附加在代码段之后
