
# nc文件

nc（Nano C）文件是存放Nano C源代码的文件，为纯文本格式的文件。

# ncc

ncc（Nano C Compiler）的作用是把一个nc文件编译为nca文件。

# nvm

nvm（Nano C Virtual Machine），即Nano C的虚拟机，可以直接执行nca文件。

# nca文件

nca（Nano C Assembly）文件是NanoC的汇编文件。可以直接由nvm（Nano C Virtual Machine）直接运行。

# nco文件

nco（Nano C Object）文件是NanoC的字节码文件，里面存放了NanoVM汇编生成的二进制，可以利用nvm执行。
